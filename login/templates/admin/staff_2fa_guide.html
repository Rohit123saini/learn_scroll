Signed in as {{ username }}: {% if has_device %}2FA is active on your account.{% else %}you do not have 2FA active yet - follow the steps below.{% endif %}

{% endif %}
  1. Install an authenticator app on your phone (Google Authenticator, Authy or 1Password).
  2. Ask someone with server (shell) access - a superuser - to run: 
    python manage.py setup_staff_2fa {{ username }}
    It prints a QR code (and an otpauth:// link). Scan it with the app. The secret is shown only on the server, never by chat or email.
  3. The app now shows a 6-digit code. Confirm it: 
    python manage.py setup_staff_2fa {{ username }} --confirm 123456
    (use your real code instead of 123456). If it says wrong/expired, check your phone's clock and retry.
  4. The command then prints 8 one-time backup codes - shown only once. Save them somewhere safe; each works once if you lose your phone.
  5. Log in at the admin login with your password and the 6-digit code.

Lost your phone?

Use a backup code in the code box. Then ask a superuser to run python manage.py setup_staff_2fa {{ username }} --reset and enrol again.
